# Glossary

- **Starter**: immutable runnable application state before the measured change.
- **Task contract**: fixed behavior, exclusions and acceptance for one selected task.
- **Arm**: one isolated implementation from the same starter and common stack.
- **Complete-run tokens**: recorded coordinator and descendant usage, including review,
  retries, recovery and compaction, with declared first-use costs and no double count.
- **Native acceptance**: actual operation and persisted recovery evidence, separate from
  registration, dependency presence, publication and final target-branch acceptance.
